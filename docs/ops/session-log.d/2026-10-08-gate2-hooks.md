- C4: the brief's sentence reads as if worktrees under `.worktrees/`, `.claude/worktrees/`, `work/lanes/` are drift when unlisted. That would invert the existing exemption (20+ lane worktrees, this lane's own, would fail) and contradict the C4 header. - Pre-push step 2c's tombstone comment names the removed command. That text incidentally satisfies F54's substring parity for CI's validate-commits job (without it F54 reports 2 violations on the live tree, confirmed by running its `check()`). The proper fix is a dated F54 EXEMPT_STEPS entry (GATE-3 territory); once it exists the path can leave the comment.
- Coordinator rulings on PR 998 (2026-10-08): (1) C4 reading stands. (2) GATE-3 deletes F54; the pre-push step-2c tombstone comment that names the removed command stays until then, and GATE-3 removes it once F54 is gone. (3) Trailer fine. (4) Write-set expansion granted for `governance/check-pretooluse-wired.mjs` (done, below). (5) `push_` and `merge_` added to `MCP_WRITE_PREFIXES`, so `push_files` and `merge_pull_request` are writes again (denied without the skills, asked with them). (6) Interpreter case, below.
- Interpreter inline code: `dangerIn()` runs DANGER over the command's own argv AND over the `-c` / `-e` argument (bundled flags such as `-lc`, `--command`, `--eval` too) of a simple command whose first word after env assignments is psql, bash, sh, zsh, node, python or python3. A shell interpreter's argument is analysed as a command line (recursively, depth 3), so `bash -c "echo 'git push is documented'"` stays quiet; a code interpreter's argument (SQL, a script) is read as written. Tested: `psql -c "delete from t"` and `bash -c "git push"` deny with no skill loaded; `echo "delete from t"` allows. Not covered: an interpreter fed through stdin or a script file (`bash script.sh`), and a payload built by shell expansion.
- `check-pretooluse-wired.mjs` now exports a pure `wrapperSourceDelegates(src)`: a wrapper passes if it spawns the gate (the current shim) OR imports the gate, calls its `runGate` and awaits it at `if (inScope) await ...`; an importing wrapper whose in-scope call is not awaited FAILS, because the trailing `allow()` would run first and bypass the gate. Its CLI body is now behind `isMainModule`, so the test file `check-pretooluse-wired.test.mjs` (new, 6 tests, attack cases included) can import it. The current spawn shim still passes the live check.
- Commit trailer uses the model name given by the session attribution reminder (Claude Sonnet 5.5), not the COMMON.md text.
