## Decisions (the brief left these to the lane)

- Output by need kind: lineage-gap becomes a portal candidate (the ledger the EUR-Lex register walk already feeds
  for a CELEX parent, G5-NEED); term-need, holdings-need and flywheel-gap become census rows (lane C, the document
  enters the gap census).
- Rating by host alone, not by host plus the author's institution text: with a name the D14 residue rule rates
  almost any host at tier 7 or by name keywords, so the "unrated host needs a verdict" clause would almost never
  bite and an author-chosen name could lift a host. Name-free keeps the verdict path the one route to a class.
- A below-floor tier is recorded, not refused (rule 18); the need closes through `holdingQualifies` at the
  generator.
- Resolve means resolved with a marker, and the export skips a need whose key was served. A generator that
  re-derives the need from a standing condition may raise it again under a new flag id; the export does not list it.
