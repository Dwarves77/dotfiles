input context today. So as of this run:

  (never blank, never invented) but is not yet "wired to the assessment model" in the data-flow sense
  the lane's title implies.

**Built.** `canonical-pipeline.ts` gains `buildPlanningAssumptionContext(sb, itemId)` (exported for
testability), called only when `it.item_type === "research_finding"` (every other item_type is
untouched - verified by the fixture test's own text-match assertion). It assembles a named
`"RESEARCH ASSESSMENT CONTEXT"` block, spliced into the synthesis `user` message on its own line

  F38's 1000-row threshold; platform is single-tenant pre-pilot scale) and calls
