### F67 (new fitness function + test, negative-tested)

Added `fsi-app/.discipline/fitness/functions/F67-unguarded-main-invocation.mjs` plus
`F67-unguarded-main-invocation.test.mjs` rather than extending F44: F44's own check is deliberately
scoped to the ONE broken `import.meta.url === \`file://${argv[1]}\`` idiom (its header says so), and
this is a structurally different defect (no guard at all, not a broken one), so a second function keeps
each check's regex simple and its own test suite legible, matching the one-function-per-defect-shape
convention `F44`/`F60`/`F61` already use.

F67 flags a line starting with `main(`/`await main(`/`main().catch(` unless the same line or the
immediately preceding code line carries a recognized guard token (`isMainModule(`,
`fileURLToPath(import.meta.url)`, or `pathToFileURL(`, all three are live, correct idioms in this repo;
F67's job is "is there any guard at all", not "which one", which is F44's job for the specifically broken
one). Negative-tested: RED on a bare `main().catch(...)`, RED on a bare `await main();`, GREEN on both
guard forms, GREEN on a comment-only mention, and an ATTACK test proving a comment-only `isMainModule`
mention two lines above a bare call does NOT suppress the finding.

**Scope decision, stated plainly:** F67's `enumerate()` is scoped to
`fsi-app/scripts/producers/**/*.mjs` and `fsi-app/scripts/gen/*.mjs`, the producer/seeder domain this
lane owns, NOT the full `fsi-app/scripts/**` plus `fsi-app/.discipline/**` tree the dispatch's wording
suggested. Reason: a first full-tree run of the same check found roughly 40 pre-existing instances of
this exact shape outside this domain, including the core discipline engine itself
(`.discipline/runner.mjs`, `.discipline/fitness/runner.mjs`, `.discipline/consistency/runner.mjs`) and a
long tail of `entities/`, `propagation/`, and `.discipline/rendering/` capture scripts. That is a real,
separate, much larger remediation than this lane's write set; landing a CI gate that goes red for ~40
pre-existing files the moment it merges would get the gate reverted, not the files fixed. Per rule 13
(a flag is a commitment), this is recorded here by name rather than silently dropped, and a follow-up
task is spawned for a dedicated lane to widen F67's scope once that remediation lands. F67 passes clean
(0 violations) on its current scope; the fitness runner (`node .discipline/fitness/runner.mjs
--function=F67`) confirms 25 files checked, 0 violations.
