## Decisions

- A term that is not adopted is not held by any reader; a read failure holds nothing (fail closed to code constants).
- Scenario tags derive only when kebab-case (the parser's own shape rule); a compliance key is taken as stored.
- A material adopted term mints an entity but is NOT detected as a mention in entity-resolve (the brief wires only
  `standard` as named; a topical material word wired by title would reopen the "same batteries?" moat).
- No `maintenance.d` file and no `.tsx`: nothing here is a maintenance step or a screen.
