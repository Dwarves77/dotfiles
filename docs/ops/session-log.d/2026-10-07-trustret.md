## Decisions (by rule, none waiting on a human)
- "Pause read" is the emergency stop `global_processing_paused` only, not `isGloballyPaused` (which also reads cadence `off`). Reason: `pause.ts` states the emergency stop is a hard halt for every caller and cadence `off` is dormancy; cadence `off` is permanent in build mode (rule 16) and `recompute-tiers` already has its own cadence hold (`held_cadence_off`), so treating it as a stop would switch both steps off for the whole build.
- The trust-score pass writes no tier column, so no `tier_override` check applies to it; the route's own score update carried none either. The override guard stays on the tier writer (`recompute-tiers`, `notUnderTierOverride`).
- `closure-gate.mjs` held no trust-recompute entry (no `HARNESS_FAMILY_BY_WORKFLOW` key, no NEVER-RUN allowlist entry); workflow targets are derived from tracked files, so the delete is enough. Unedited.
