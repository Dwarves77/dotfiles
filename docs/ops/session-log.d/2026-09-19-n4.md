   and ran `git diff --numstat` against the staged, now-also-NUL-free index: `1 0 execution-wiring.mjs`, a
   real line-based diff; reverted the throwaway line with `git checkout --` (working tree now matches the
   staged fix exactly, confirmed by an empty follow-up diff), then unstaged. From the commit that lands
   this fix onward, every future diff of this file is textual; the one commit that removes the NUL is the
   one diff that cannot be, since its own parent still has it.
