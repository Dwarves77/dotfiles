uses `surface` for (a) the breadcrumb text (`[surface, jurisdiction].filter(Boolean).join(" / ")`) and

`open-ask-assistant` `CustomEvent`'s `detail.scope`. `AskAssistant.tsx`'s listener destructures only
`{ question, anchor }` from that event detail, `scope` is not read anywhere downstream `[CONFIRMED]`
by reading `AskAssistant.tsx`'s handler and grepping every `open-ask-assistant` listener in `src/`
(2 files: `AskAssistant.tsx`, `ResearchLedger.tsx`, the latter is a dispatcher, not a listener). The
rename is therefore breadcrumb-only in effect; no functional consumer branches on the exact string.

**Test checked:** `src/lib/detail/meta-line.npmtest.mjs` asserts a `"Market / <publisher>"` string, but
