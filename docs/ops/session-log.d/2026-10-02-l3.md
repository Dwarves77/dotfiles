## Built

- `fsi-app/scripts/research/openalex-client.mjs` (new) - thin fetch wrapper over OpenAlex `/works`,
  `/authors`, `/institutions`, plus a topic-scoped `/works` group-by helper
  (`fetchInstitutionTopicStanding`) for the spec's "institution FWCI in the specific topic" requirement.
  Polite-pool `mailto` on every request (defaults to the platform's existing public contact address,
  `privacy@carosledge.com`, already live on `src/app/privacy/page.tsx` - no new credential-shaped value
  invented, overridable via `OPENALEX_POLITE_EMAIL`). No API key anywhere. Retry/backoff on 429
  (honors `Retry-After` when present, exponential otherwise); 404 returns `null` (honest absence, not
  an error); any other non-2xx raises `OpenAlexError` with the status and path. `deps.fetch`/`deps.sleep`
  injected, defaulting to the global `fetch` (Node 24 native) and a real `setTimeout` sleep.
- `fsi-app/scripts/research/authority-score.mjs` (new) - pure scorer. Role class (the spec's nine-value
  vocabulary, mapped from OpenAlex/ROR institution `type` plus a named-body override table for IEA/IMO/
  EASA/ICCT/Smart Freight Centre/TRB-TRID, which OpenAlex's generic `type` field mis-sorts or cannot see
  at all); topic-scoped institutional/author standing (returns `null` on absence, never a brand-level
  fallback - the spec's own "MIT said it" failure mode); funding independence as the spec's explicit
  three-state rule (`independent`/`dependent`/`unknown`, never collapsed); reception via FWCI or
  `citation_normalized_percentile`, with the under-24-months velocity substitute (citations-per-month,
  documented as a simplification against the spec's "subfield cohort" ask, since no cohort baseline is
  wired into this lane's input shape) and a negative-tested guarantee that no output object ever carries
  a `cited_by_count`-shaped key; integrity (retraction flag, explicit `unknown` for `predatoryVenue` when
  no DOAJ-equivalent signal exists, never defaulted to `false`); the grey-literature non-citation path
  (institutional mandate + method transparency + independent replication + cited-by-indexed-literature,
  reaching `highAuthorityIndependent` on mandate alone with zero citation signal, per the spec's
  "never let absence of a citation footprint read as low authority" rule); `aggregateAuthorityDistribution`
  returning bucket COUNTS plus the per-source detail array - never a mean, matching the spec's own
  worked example ("3 high-authority independent, 1 medium, 2 vendor-flagged") and adding an `unknown`
  bucket plus a cross-cutting `integrityFlagged` count the spec's own rules require but the chip's
  current 3-bucket consumer shape does not yet carry (see Open items).
- `fsi-app/scripts/research/openalex-client.test.mjs` (new) - 17 tests, fixture-based, zero network:
  polite-pool mailto, extra query params, 429 retry/backoff (exponential and `Retry-After`), exhausted
  retries raising `OpenAlexError`, 404 to null, non-404 failure to `OpenAlexError`, no-fetch-available
  error path, DOI normalization (bare/`doi:`/full URL, all three forms resolve to the same request
  path), ORCID vs bare-id routing for authors, ROR vs bare-id routing for institutions, the
  topic-standing group-by query shape.
- `fsi-app/scripts/research/authority-score.test.mjs` (new) - 32 tests, zero network, zero DB: role
  class mapping and named-body overrides, institutional/author standing absence, the funding-
  independence three-state negative test, FWCI-suppression-under-24-months with the velocity substitute
  (and the negative test that the suppressed FWCI value never leaks through as the velocity value),
  the "never raw `cited_by_count`" negative test (greps the output object's own keys, not an eyeball
  read, per the brief), integrity defaults, every `bucketForSource` branch (vendor-always-flagged,
