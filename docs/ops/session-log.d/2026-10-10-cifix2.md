## Accomplished

1. `fsi-app/.discipline/governance/docs-only-range.mjs`: `extractReadDocPaths` is token based. A local `lexJs` groups the per-character classes of the one source lexer (`source-lexer.mjs`, GATE-8) into string tokens, template tokens (interpolations lexed as nested token lists, left as a hole in the static text), identifiers and punctuation. A docs-like literal is a read when it is inside the parentheses of a read, exist, stat, resolve, join, open, load, require or import style call at any line distance; when it is bound to a SCREAMING_CASE constant; or when it is bound to any other name that reaches a read call in the same module (a path built in one statement and read in a later one). A `join()` or `resolve()` of literal arguments spread over lines forms one path. A template with a variable prefix (`${root}/docs/x.md`) names `docs/x.md`; an interpolation after the docs root becomes a one-segment `*` (`docs/zz/${name}.md` governs every `.md` directly under `docs/zz/`), matched by `isGoverningDocPath`. Array elements, object property values (a fixture field such as `file_path`), prose, non-read call arguments, comments and regex bodies are not reads. [CONFIRMED: node --test docs-only-range.test.mjs, 33 pass]
2. `fsi-app/.discipline/governance/docs-only-range.test.mjs`: DO-AST-1 (template prefix, glob, mid-path hole), DO-AST-2 (multi-line call and join), DO-AST-3 (binding then read, SCREAMING constant, unused binding and fixture field not read), DO-AST-4 (comments, prose, lists, non-read arguments, regex body, quote noise), DO-AST-5 (attack through real git: an edit to a doc read only through a `${root}` template gives `docs-only: false`, an unread doc gives `docs-only: true`).
3. `.github/workflows/research-assessment.yml`: the landing step checks the exit of `record-harness-run.mjs` explicitly (exit 2 is the developer-local self-skip, any other non-zero is `::error::` plus `exit 1`), the form research-walker.yml has carried since PR 1056. The status is captured with `|| status=$?` so the shell's `-e` does not end the step before the branch runs.
4. `fsi-app/.discipline/governance/landing-step-no-swallow.test.mjs` (new, shape test over EVERY workflow): LAND-1 no step named `Land ...` and no line running `record-harness-run.mjs` carries `|| echo`, `|| true`, `|| :`, `|| exit 0` or `; true`; LAND-2 attack, each of those forms is red (also on a renamed step, and on any swallow inside a `Land ...` step); LAND-3 the explicit exit branch, a non-landing step and a comment are not flagged.
