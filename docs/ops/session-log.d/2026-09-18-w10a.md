**ListRow.tsx's column header** (`"Impact"`, was `"Impact low-to-high"`): a copy-only change. The reader's goal at the column header is unchanged (know what a column compares before reading rows down it); the qualifier is dropped because it no longer describes what the column shows (the meter stopped sorting dimensions low to high), so the label now names the thing accurately instead of misleadingly (law 16, pattern consistency: a label should describe its column's real encoding). No action, no async state.

**The impact meter, row block** (`ImpactMeter.tsx`'s row variant, mounted inside every `ListRow`, every list surface: Regulations, Market, Research, Operations, Watchlist, Dashboard's two cards): goal is to read an item's total impact at a glance and compare it against neighbouring rows without opening any of them (Prägnanz: one visual encoding, four bars filling left to right, one colour, reads faster than four separately-coloured dimension bars did). Path: none, it is a passive display element; the ONE primary action on the row remains opening the item (the whole row is still the click target, unchanged by this lane). No async action, no loading/success/failure state: the meter derives entirely from data already on the row (`impact` prop), nothing it renders is fetched separately. Not an interactive target itself (`aria-hidden` on every bar), so the law-2 44/24px floor does not apply to the bars; the row's own click target (min-height 56px) is unchanged. Screen-reader text: `aria-label="Impact N of 12"` / `"Impact not scored"` on the outer span (unchanged mechanism, the wording is current); the unscored state's em dash carries its reason on `aria-label`/`title` via `Absence`'s existing `dash` convention, not as visible text (no new failure-without-explanation state introduced).

**The legend row** (`ListSurfaceRailCards.tsx`'s `LegendRailCard`, the "Impact" entry, every list surface's rail): goal is to understand what the meter's bars and colour mean before reading the list below it (law 5, chunking: a definition read once, not re-derived from the data). Path: none, a static rail card, no interaction. Before this lane it showed prose describing the OLD model with no live meter at all; it now mounts the real `<ImpactMeter total={8} />`, so the legend is truthful about what the list actually renders (was a documentation-drift risk, law 3, familiar/accurate patterns). No primary action, no async state.
