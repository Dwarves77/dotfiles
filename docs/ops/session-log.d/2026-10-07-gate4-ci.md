## Decisions

- Rendering guard at depth 1 is safe for the guard's own oracle: `latestTrainWave()` returns null on a depth-1
  PR checkout; both dated exemption lists fail closed on null (expiry waves 58 and 70, latest landed wave
  71, so none is active either way) and `CARD_DEVIATIONS` in `manifests.mjs` is empty with log rows carrying
  `expiryWave: null`. Confirmed by reading those three files.
- Artifact name: `gate-firings-<job>` and not the single name `gate-firings` in the brief, because
  `upload-artifact@v4` refuses a second upload under one name in a run and the two files come from two jobs
  on two machines. The prefix is shared so `--pattern 'gate-firings-*'` selects both.
- `retention-days: 7`: F68 (actions-artifact-budget) fails any upload step above 7 days.
- Concurrency is an explicit count with a floor of 2, not `true`, so a 2-vCPU runner still overlaps files.
