## Decisions (by rule, none waiting on a human)
- `run-data-audit-lane.mjs` needed no edit: its audit list is DERIVED from each script's own `// data-audit:` marker (plan 6.8 Rule A), so the registration is the marker line in `section-marker-audit.mjs`.
- No `npm ci` step in the workflow: the runner imports only relative modules and Playwright, installed with `--no-save` exactly as the rendering-guard job does.
- The credentials are only sent to `carosledge.com` or a `*.vercel.app` host (`live-preflight.mjs`), so a dispatch with a mistyped or hostile URL cannot send them elsewhere.
- Allowance: the new attribute is `data-overflow-allowed`; `data-guard-strip` is accepted as the same declaration because the theme strip and other strips already carry it and a `.tsx` edit is outside this lane. A declared scroller's own box must fit the viewport, and its ancestors are still held to the rule, so the 1108px strip fails on its own box and on `<main>`.
- Score rule: a bare decimal is a score when it is a whole text node or follows a scoring word (density, score, centrality, weight, similarity, confidence, relevance, rank, strength); ordinary figures (2.5%, EUR 1.50) pass.
- Registries edited: `secrets-registry.mjs` only. Read and not edited: `closure-gate.mjs` (see the open item below), `shared-dataset-ownership.md` (no new table writer; the audit only reads).
