## Task (c): invalid CSS var-concatenation tint fix, CF-BROKEN-2 / A2bc's A6

- Built one shared helper, `src/lib/tint.ts`'s `tint(cssVar, percent)`, returning
  `color-mix(in srgb, ${cssVar} ${percent}%, transparent)`. Chose `color-mix()` over fixed
  `--color-*-tint` tokens because the 24 sites use four different percentages (10/15/20/50) against
  four different semantic colors (`--color-error`, `--color-primary`, `--color-success`,
  `--color-warning`); a fixed-token approach would need up to 16 new tokens for ad hoc combinations,
  against the dispatch's own "one shared helper" framing.
- Replaced all 24 `"var(--token)NN"` string-concatenation sites (exact count confirmed by
  `grep -rno 'var(--[a-zA-Z0-9_-]*)[0-9]\{1,3\}' <5 files> | wc -l` = 24 before the fix, 0 after,
  across the whole `src/` tree):
  - `CanonicalSourceReview.tsx` (9), `ProvisionalReviewCard.tsx` (7), `ThemesView.tsx` (5),
    `IntersectionDetectionView.tsx` (2), `IntelligenceMetadataStrip.tsx` (1).
  - Mechanical regex-driven replacement (`"var(--X)" + "NN"` and the bare-literal form → `tint("var(--X)", NN)`),
    then hand-verified every site's diff by re-reading the files.
- `src/lib/tint.test.mjs`: unit proof the helper never produces the old concatenation shape and
  always builds a real `color-mix()` value.
- **Second instance, A2bc's A6 (`timeline-dot-styles.ts`'s `nextDotStyle`):** this was the SAME
  defect class via template-literal interpolation (`` `...${bandHex}33` `` where `bandHex` was
  `band.cssVar`, a `var()` reference) rather than `+` concatenation. Root cause: `UrgencyBand`
  (`src/lib/urgency/bands.ts`) already carries a raw hex field (`hex: string`, e.g. `"#DC2626"`)
  alongside `cssVar`; both live call sites were passing the wrong one. Fixed by repointing the call
  sites, not by adding a new field (reuse-before-construction: the field the dispatch suggested
  adding already existed):
  - `src/components/ui/Timeline.tsx:178`: `nextDotStyle(band.cssVar, 12, 3)` → `nextDotStyle(band.hex, 12, 3)`.
  - `src/components/ui/ListRow.tsx:685`: `bandHex={band.cssVar}` → `bandHex={band.hex}`.
  - Strengthened `nextDotStyle`'s own JSDoc in `timeline-dot-styles.ts` to state the raw-hex
    requirement explicitly, so the shape cannot drift back silently.
- **Fitness gate added: F62 (`no-css-var-concat`)**, `.discipline/fitness/functions/F62-no-css-var-concat.mjs`.
  Scans all `src/**/*.{ts,tsx}` for a `var(--token)` reference immediately followed by 1-3 digits (no
  delimiter), catching both the `+`-concatenation and template-literal forms, while explicitly NOT
  matching a real `color-mix()` argument (`var(--token) 50%`, space before the digit) or a
  comma-separated list. `tint.ts` itself is exempt (it documents the defect shape verbatim in its own
  header comment). Negative-tested per rule 15 in `F62-no-css-var-concat.test.mjs`: 3 RED cases (the
  `+`-form, the template-literal form, the already-joined-literal form), 5 GREEN cases (the fixed
  `tint()` call, a real `color-mix()` argument, a bare `var()` with no digit, `nextDotStyle` with a
  hex literal, `tint.ts`'s own exemption), plus a LIVE sweep of the real `src/` tree. `[CONFIRMED]`:
  `node --test .discipline/fitness/functions/F62-no-css-var-concat.test.mjs` → 10/10 pass, including
  the LIVE sweep. `node .discipline/fitness/runner.mjs --function=F62` → PASS (601 files checked).
