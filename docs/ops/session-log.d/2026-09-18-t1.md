## 2026-09-18, W9 lane T1: the no-credential test for the vocabulary-drift check reads no env file

Coordinator fix, worktree wt-hashsep-0911, branch `lane/t1-hermetic-no-credential-test-2026-09-18`, cut from
master `020da516`.

**What happened [CONFIRMED by reproduction].** Lane M2's push was refused by
`fsi-app/scripts/verify/check-vocabulary-drift.test.mjs` (2 of 4 failing), on a tree where M2 had changed
nothing near it. The test strips four credential variables from the child's environment and expects the
script to self-skip with exit 2. The script then loads `fsi-app/.env.local` from disk, so in a worktree that
has that file the credentials come straight back: plain run, the script connects and does not exit 2; under
the no-npm resolver hook it reaches the `pg` import and exits 1. Only the one worktree that carries an env
file (wt-session-d, the relay worktree) fails; every lane worktree and CI pass. Four test files in the repo
assert a no-credential self-skip; run in that worktree, only this one failed.

**The fix.** `check-vocabulary-drift.mjs` skips its env-file load when `CHECK_VOCAB_DRIFT_NO_ENV_FILE=1`
(the load stays inside its try, so F48 holds); the test's `noCredEnv()` sets it. No behaviour change for any
real run.

**Proof, both directions, same disk state** (a throwaway gitignored env file holding one fake connection
string, removed afterwards): master's script under the no-npm hook exits 1; the patched script with the flag
exits 2; the patched test file passes 4 of 4 with the env file present.

**Found on the way, recorded for plan section 6.8.** The push queue carried a rule that ran
`git rebase --skip` when a commit's only conflict was a harness marker. On a one-commit lane that drops the
whole lane. It fired exactly once in the logs (2026-09-13 to 2026-09-18), on M2 tonight, and this test
failure is what stopped the empty branch from being pushed. The rule is removed from the coordinator's
queue; the queue now also refuses to continue when a rebase leaves a lane with zero commits ahead of master.
