## API contract for lane G7-UI (full text at the top of `src/lib/corrections/admin-api/logic.mjs`)
- All routes: platform admin only (401, 429, 403 from `requireAdminRoute`), rate-limit headers on every response. Errors are `{ error, code }`.
- `GET /api/admin/items/{itemId}/corrections` -> 200 `{ item_id, counts: {active, revoked, orphaned}, corrections: [ {id, item_id, target_kind, target_ref, op, value, machine_value, reason, created_by, created_at, revoked_at, revoked_by, revoked_reason, active, superseded, orphaned, latest_machine_value, machine_observed_count, machine_observed_at} ] }` newest first; 404 `item_not_found`. `orphaned` is true for an ACTIVE fact correction matching no current claim.
- `POST /api/admin/items/{itemId}/corrections` body `{ target_kind, target_ref, op, value?, reason }` (reason mandatory, `created_by` never read from the body) -> 201 `{ id, item_id, applied: true }`; 400 `reason_required|target_kind_invalid|op_invalid|target_ref_required|target_ref_invalid|value_invalid|fact_needs_span|invalid_json`; 404 `item_not_found|claim_not_found|section_not_found`; 422 database refusals (`fact_span_not_verbatim`, `fact_failed_validation`, ...).
  - target_ref: fact = claim id, tag = `<topic_tags|operational_scenario_tags|compliance_object_tags>:<tag>`, connection = the other item id, section_text = section_key, full_brief = `full_brief`.
  - ops: fact suppress|replace, tag add|remove, connection add|remove, section_text replace ({content_md}), full_brief replace ({text}); fact replace value {source_span, search_result_id, claim_text?, source_id?}. A fact `add` is NOT offered (a claim belongs to a section; add a fact by replacing the section text).
- `POST /api/admin/items/{itemId}/corrections/{correctionId}/revoke` body `{ reason? }` -> 200 `{ id, item_id, revoked: true }`; 409 `correction_not_active`. Revoke RESTORES the machine value (above).
