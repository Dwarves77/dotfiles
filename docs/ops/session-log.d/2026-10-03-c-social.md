# 2026-10-03, lane C-SOCIAL: Community is social only (ADR-041, migration 348)

## Ruling

Operator, 2026-10-03, verbatim: "Community is a resource for people to discuss what they're doing in
their own regions and how they're working through things if they wanna link a regulation or something
that they wanna talk about from the system that's OK, but we should not be using community to feed data
into the rest of the pages absolutely not." And: "It is a social place. It is not a source of
information." Decision record: `docs/decisions/ADR-041-community-is-social-only.md`.

## Step 0

The cancelled L16 worktree (`lane/l16-promotion-machine`) was discarded: tracked edits reverted, untracked
files cleaned, worktree removed without `--force`, branch deleted.

## What was removed

Every outbound path from Community: the peers strip on three detail pages, the Map dots and legend row,
the Dashboard Community pulse, count and rail stat, the nav Community count, the admin pickups queue, tile
and counts, the promote route and dialogs, the promotion ladder (corroboration route, lineage guard,
decay, chips), the Community promotion and origin fields in selects and types, and the health map count.
Full list in the ADR. Migration 348 (authored, not applied) drops `post_promotions` and five columns on
`community_posts`.

## Read and reused

Read the write set and each file's importers by grep before editing. Reused the existing
`SectionCard`-based Community layout untouched; no new component was added. The entity threads route and
`EntityDiscoveryPanel` stay because they are inside Community.

## Findings recorded (rule 14 labels)

- [CONFIRMED, grep] `fetchInstrumentEntityId` and `decay.mjs` had no consumer other than the removed strip
  and age chip, so both were deleted.
- [CONFIRMED, read of migration 041] The partial index on `promoted_to_item_id` is named
  `idx_community_posts_promoted_to_item`; migration 041 has no index on `promoted_at`, so 348 drops the
  real index names (that one and `idx_community_posts_promotion_state` from 295).
- [CONFIRMED, read] `scripts/maintenance/lib/origin-class-map.mjs` and
  `scripts/spec09/oem-roadmap-producer.mjs` still assign `community-corroborated` or `community` to
  non-Community items, so the spec 00 sentence was worded "no Community producer assigns" rather than "no
  producer assigns". Whether those producers should keep those values is a separate ruling, not made here.
