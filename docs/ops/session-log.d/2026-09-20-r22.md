## 2026-09-20, lane R22: rule 022 exempts the operator's delivered design-bundle files

What changed: `fsi-app/.discipline/rules/022-no-dash-glyphs.mjs` gains one more exempt-path class in
`isExemptPath`, anchored by a new regex constant `DESIGN_HANDOFF_BUNDLE_FILE_RE`:

```
/(^|\/)docs\/design\/handoff-\d{4}-\d{2}-\d{2}\/(README\.md|support\.js|[^/]+\.dc\.html)$/
```

A path matches only when it is one of the bundle's own delivered files (`README.md`, `support.js`, or
any `*.dc.html`) directly inside a dated `docs/design/handoff-YYYY-MM-DD/` folder. The check is a new
helper function `isDesignHandoffBundleFile`, exported as `isDesignHandoffBundleFileExempt` for reuse by
any other checker that would need the same exemption (none found, see below). The header comment's
exempt-class list and the fail message's exempt-path list were both updated to name the new class.

Why [CONFIRMED 2026-09-20 by the pre-commit hook, per the dispatch]: the operator's Claude Design
bundle at `docs/design/handoff-2026-09-07/` (`Caros Ledge UI System.dc.html`, `README.md`, `support.js`,
screens) could not be committed. Rule 022 counted 205 added lines with a banned dash/section-sign glyph
in the canvas HTML. The rule's own header already treats verbatim third-party content as data, not
prose this repo authored, and already exempts three verbatim classes by path (record-briefs batches,
`fixtures` directories, `docs/archive/`). A design bundle delivered by the operator is a fourth verbatim
class: it cannot carry a per-line `glyph:verbatim` marker without altering the artifact. The change adds
that fourth class, scoped to the three specific delivered files, not the whole folder, so repo-authored
files that sit beside the bundle in the same dated folder (`DEVIATION-LOG.md`, `HANDOFF.md`,
`AUDIT-*.md`, `SHARED-PART-REPORT-*.md`) stay under the rule as before.

Tests added to `fsi-app/.discipline/rules/022-no-dash-glyphs.test.mjs`, following the file's existing
pass/fail style and its \u escape convention for building glyphs at runtime: PASS for an added dash line
in `docs/design/handoff-2026-09-07/Caros Ledge UI System.dc.html`, in `.../README.md`, and in
`.../support.js`; FAIL (attack form) for the same line in `docs/design/handoff-2026-09-07/DEVIATION-LOG.md`,
in `docs/design/README.md` (no dated handoff segment), in `docs/design/handoff-2026-09-07/nested/README.md`
(not directly inside the dated folder), and in `docs/design/handoff-notes/README.md` (no date in the
folder name). 28 of 28 tests pass (7 new).

Other checkers scanning for the same glyphs [CONFIRMED by `grep -rn 'u2014\|u2013\|00A7\|00a7'` over
