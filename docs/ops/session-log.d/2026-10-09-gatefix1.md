## Accomplished

- Item 1, Read evidence: a whole, resolved `Read` of `fsi-app/.claude/skills/<slug>/SKILL.md` now counts as the skill
  looked at, equal to a resolved Skill call (`skillConsultedInTranscript`, used by `missingFromTranscript`). Any path
  spelling counts (slash or backslash, case, relative, `.` and `..`, a worktree copy). A slice (offset other than 0, or
  any limit), an errored or result-less Read, another slug, a references file, a Bash `cat` and a prose mention do
  not. The deny text names the Read path first and says the harness may serve a stale registry copy while the file on
  disk is current. Before this change a Read only reached an unsatisfiable-demand allow; it now reaches the same ask a
  Skill call reaches.
- Item 2, honest forms: in `dangerIn`, a simple command that is `git merge-tree` in any form, `git push --dry-run` (or
  `-n`, not cancelled by `--no-dry-run`), `grep`/`egrep`/`fgrep`/`head`/`tail`, or `rm -r` whose every path argument
  resolves strictly under the OS temp dir (which holds the session scratchpad), `/tmp`, `GATE_SCRATCH_ROOTS` or a
  `fsi-app/scripts/tmp/` directory is blanked before the DANGER and structural checks. Paths are resolved through links
  (a junction out of a root does not carry a delete out), a glob, `$`, `~` or brace refuses, the root itself refuses.
  Every other segment of the same line is judged as before.
- Item 3b: a dispatch message whose text carries `file:line -> [TOKEN]` pairs (also `=>` and the arrow glyph escape)
  with a well-formed disposition token for every currently open finding is a disposition act and reaches the normal
  ask. A partial message is refused naming how many it covers and which are uncovered. The literal DISPOSITION-LANE
  is unchanged.
- Item 3: `collectOpenFindings(root, { registerGraceMs, now })`: a gitignored scratch register younger than
  `REGISTER_GRACE_MS` (24 hours, by mtime) is skipped by the dispatch gate; the refusal names file, line and
  `register Nh old`. Audits and session logs are never skipped. The CLI default stays 0 (reports every register).
