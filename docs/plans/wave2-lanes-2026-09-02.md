## Lane contract additions since Wave 1
1. **F34**: no filesystem call at module scope under `fsi-app/src/**` (fitness fails it). No `node:fs`
   import in any module a page can reach, even inside functions, unless the brief says so.
2. **Route files export only route handlers** (`GET`/`POST`/…, `runtime`, `dynamic`, …). A pure function
   for testing lives in a sibling module. `next build --webpack` fails on the existing offenders;
   BUILDGATE fixes them; no new ones.
3. **Page-graph proof**: a lane that touches anything under `src/app/**` or a component a page imports
   runs `cd fsi-app && NEXT_TELEMETRY_DISABLED=1 npx next build --webpack` before handoff and pastes the
   result. Known: Turbopack refuses the worktree's symlinked `node_modules`; `--webpack` does not. If the
   build fails on a pre-existing offender BUILDGATE owns, say so and continue; anything your lane added
   must build.
4. Migrations: numbers are assigned here; a lane that needs one it was not given stops and reports.
