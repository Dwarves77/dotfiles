## 8. Build plan for this module

The brief's module notes, answered per group. **Producers** build the structured reads: Market's comparative numerical rows (market_series, published_price_statistics; spec 02 sections 1 and 6), Operations' jurisdictional data (regional_data_facts, grid_connection_queues, state_cost_facts; spec 04 sections 1 and 6; spec 09 sections 1.5 and 1.6), Market's domain extensions (oem_tech_roadmaps, reroute_events, indexation_clauses; spec 09 sections 1.1, 1.3, 1.7) and Research's horizon assessments (research_assessments, signposts; spec 03 sections 2 to 4 and 7). Regulations' compliance-action text is not produced here (it is minted and briefed by P1-14 and the brief contract); the analysis-construction-spec skill (fsi-app/.claude/skills/analysis-construction-spec, v2.2) governs the four non-regulatory brief formats, which read these tables through the surfaces. Each producer: fetches one free public source, parses it purely, plans a keyed upsert, writes through the guarded path with its source rated by the institution class table, then triggers its downstream (derivation edges, summary, run artifact). Where the surfaces read: section 2's table list, and section 1's reader census (market/[slug]/page.tsx:162,253; supabase-server.ts:2344,3429,3561,3681,3740,4909; the five panel components; research/page.tsx:46; research/[slug]/page.tsx:215; canonical-pipeline.ts:871; trust.ts:1001,1379). What triggers them today: nothing scheduled (section 1 dispatch evidence); the operator's `drain` command for the drain planner; the propagation drain runtime and the population flywheel for the learning loop, both themselves undispatched on this tree. **Drain** is the learning loop's answer mechanism: a plan of pending judgement work (verdicts, host classes, needs, questions, theme briefs, record briefs) exported from the database, authored by a session as committed batch files, applied by a step on merge. **Learning** is what the system learns from outcomes: a question raised for every minted or changed item (what, affects me, comply, invest-wait-avoid), a signpost (a dated expectation an assessment stated) scored held, refuted or partial when the watched entity changes or the date passes, and a reliability ledger row per source that grounded the assessment, read by trust.ts. **Research walker** is the free discovery runtime: grey-literature sources and OpenAlex searched for the open needs, publishers rated, candidates minted through the chokepoint. **Spec09** is the eight-domain extension of spec 09, reduced by ADR-042 to external data only: four producers, two operator-rows producers and six calculators the panels call.
