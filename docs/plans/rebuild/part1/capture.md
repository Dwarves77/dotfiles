Core responsibilities (9), with the files that carry them today:

1. Document capture: the only code that fetches a source body and stores it as a grounding capture (capture-worker/index.ts). Reads `pending_first_fetch`, claims the row atomically, fetches with a real-browser header set and a 45 s timeout, retries a 403 once with a second fingerprint, caps the body while streaming (25 MB PDF, 50 MB text), extracts PDF text with unpdf, decodes by declared charset, strips U+0000, refuses error pages and bodies under 1,000 chars, stores the full text in `agent_run_searches.result_content` with the ADR-016 ceiling bound LOUD (a coverage_gap flag), records every outcome in `agent_runs`, re-queues transient failures up to 5 attempts.
2. Change detection: the check-sources pass (check-sources/logic.ts, route.ts). Gated by the scrape OFF gate and the scrape-day window, selects active unpaused auto-run sources not yet checked this UTC day, assesses reachability through a pure decision (a non-answer never evicts), fingerprints the rendered text, writes `sources`, `source_trust_events`, `monitoring_queue`, extracts portal deep links on root portals, then runs the reconcile pass in process.
3. Manual reconcile re-drive (reconcile/route.ts): a worker-secret wrapper over `runReconcilePass`.
4. First-party error telemetry: server capture into `error_events` grouped by a server-computed stack hash (capture-error.ts, stack-hash.mjs), the client reporter with session caps (GlobalErrorReporter.tsx) and its authenticated ingest route (api/telemetry/error).
5. D3 audit hooks (d3/hooks.mjs): admission and rejection outcome bias by method reliability, a heartbeat into `d3_runs`, an audit-event runner.
6. Surface health evaluation (surface-health.mjs): must-have surfaces with zero backing rows fail, the seed-leak signal.
7. Request instrumentation: Server-Timing store, header and log line (server-timing-core.ts, server-timing.ts); the build-time slug read with a timeout (static-params-fallback.mjs); the public version route.
8. Outbound messaging: the invitation email seam (send-invitation-email.ts, no provider); the notifications inbox writer (notifications/dispatch.ts); the seed-fallback integrity flag (seed-fallback-flag.ts).
9. Cache invalidation: the tag vocabulary and per-item flush (cache/revalidate-item.ts), the refuse-to-cache-a-fallback guard (cache/fallback-guard.ts), and two worker-secret routes that call `revalidateTag` (api/revalidate, api/cache/revalidate-item).
