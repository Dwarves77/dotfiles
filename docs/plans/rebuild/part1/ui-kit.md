## 8. Build plan for this module

### What src/ui is

The new `src/ui` is the component kit every surface composes: tokens, the base stylesheet, and the primitives below, with three rules the old tree does not hold. (1) A kit part never fetches, mutates, reads a store or dispatches an app event: it takes data and callbacks. The four parts that do today (TagPopover and DetailTagRow, WatchButton's hook, CommandBar's search and Ask, CoverageState's request action) split into chrome in the kit and a hook in the feature that owns the data. (2) A kit part carries class names, not `<style>` tags: every responsive rule lives once in `src/ui/base.css` under one breakpoint literal, so the DOM carries the CSS once. (3) Colour, type, radius, shadow and spacing reach the DOM only through `theme.css` tokens, with two declared exceptions, the ImpactMeter ramp stops (interpolated in code) and the alpha-suffixed ring (`UrgencyBand.hex`), both inside the kit and named in a test.
