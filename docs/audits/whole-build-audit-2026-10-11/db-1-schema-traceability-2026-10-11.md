Definitions. LIVE: runtime writer and runtime reader. WRITE-ONLY: writer, no reader. READ-ONLY: reader, no writer. MIGRATION-ONLY: no runtime writer or reader, only migration data statements touch it. DEAD: no runtime writer or reader and no migration data. Runtime writer = product code site, or a LIVE function body (INSERT/UPDATE/DELETE), trigger functions included. Runtime reader = product code select (incl. embedded and readAll helpers), LIVE function body, a READ view, or a policy sub-select. A writer or reader that exists only in a DEAD function, an unread view, a verify script or a test does not count (listed in the row as deadfn, unreadview, verify, test). Function LIVE = an rpc() site or word in product code, a surviving trigger, a policy, a view, or a LIVE function calling it (fixpoint); GRANT and COMMENT lines are not callers; test-only or verify-only callers leave it DEAD (shown in the row).
