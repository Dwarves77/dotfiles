## Change

Lane G5-READ (2026-10-07, buildout plan Stage 5) touches three governing files of this family so that adopted
vocabulary terms (migration 355) are read. `src/lib/agent/canonical-pipeline.ts` reads the adopted terms once per
brief pass (`adoptedTermsFromSupabase`), builds the system prompt with `buildSystemPrompt(adopted)`, passes the set
to `parseAgentOutput`, and `writeSynthesizedBrief` reads it again only when a theme outside the 7 code themes is
present. `scripts/turns/apply-record-briefs.mjs` loads the adopted terms once per run and passes them to
`validateRecordBriefsFile`, whose `scripts/turns/record-briefs/schema.mjs` hands them to `parseAgentOutput`, so a
brief using an adopted theme or compliance_object term validates the way the write boundary accepts it. A read
failure returns no adopted terms, so every path behaves as before on the code vocabularies alone. Covered by
fixture tests, not a live `brief-apply` run; migrations 355 and 357 are not applied.
